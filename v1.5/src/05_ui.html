5. 화면(UI) 설계

웹 관제 화면은 FMS가 직접 제공하는 단일 페이지(fms_server/static/admin.html)다. npm 빌드와 CDN 없이 HTML/CSS/JS(Canvas)만 쓰며, 왼쪽 메뉴로 페이지를 바꾸고 주소의 #페이지로 바로 열 수 있다. 상단에는 모든 페이지 공통으로 현장·맵 선택과 새로고침이 있다. 이 장의 화면은 2026-11-25 실제 FMS에 시뮬레이터 로봇 4대를 연결해 캡처했다(격리 브로커, 테스트 현장 test_01). 이번 개발에서 추가하는 화면(SC-00, 15~18)은 주황 점선 와이어프레임으로 그렸다.

모든 화면은 주 메뉴(SC-02)에서 바로 열리고(주소 #페이지), 화면 사이 이동은 버튼으로 이어진다. 이동 경로가 짧은 것이 설계 목표다: 실시간 맵에서 로봇을 누르면 팝업, 팝업의 [이력]이 그 로봇으로 필터된 이력, 알림의 [로봇 이력]도 같은 화면으로 간다. 이번 개발 화면(주황)은 기존 화면 안의 패널·탭·카드로 붙여 메뉴를 늘리지 않는다 — SC-15 는 실시간 맵 패널, SC-16 은 알림 위, SC-17 은 통계 탭, SC-18 은 현장 설정 카드, SC-00 은 인증 실패 시 전체 화면.

5.2 초기화면(로그인 전환면) 설계

FMS는 사용자 계정 대신 API 키로 인증한다(설비 관제 서버는 화면 사용자보다 외부 시스템·도구가 많아 키 방식이 맞다). 인증이 꺼진 서버는 접속하면 바로 실시간 맵(SC-01)이 초기 화면이다. 인증이 켜진 서버(FMS_AUTH=1)에 처음 접속하면 첫 API 호출이 401을 받고, 지금은 브라우저 입력창으로 키를 묻는다. 이번 개발에서 이를 페이지 안의 키 입력 화면 SC-00으로 바꾼다(배포 전 필수 보안 항목).
